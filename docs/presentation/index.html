03 · DUAL-PROCESS AI 04 / 08

단 1개의 완결된 문장만 적는다

객관식 보기를 나열하지 않고, 최우선 맥락에 맞춘 단일 가설 질문을 한글 획순으로 대필

INPUT 필기 획 / 취소선 Zero-Retention Crop
→
SYSTEM 1 Jev / OpenJev Noul · Choice · Box
→
SYSTEM 2 Writer Engine 단 1문장 한국어 질문 대필
→
FEEDBACK O / X 제스처 루프 흡수(Sink-in) vs 기각(Pivot)
동그라미 (O) 제스처 — 종이 속 흡수

AI 제안 문장에 사용자가 O를 그리면 문장이 종이 아래로 스며들며 사라지고, 추출된 핵심 어휘가 EvolvingContext에 영구 누적됩니다.

엑스 (X) 제스처 — 오답 제약 피벗

AI 제안 문장에 X를 그리면 해당 문장이 오답 목록(Negative Constraint)에 즉시 추가되며, 이전 방향을 배제한 다음 최선책 문장 1개를 새로 추론합니다.
