### 확인하는 방법 · 3단계 이내
1. **신규 온보딩 플로우 및 AI 필기 동의 판정 체험**:
   * 로컬 서버 실행 (`npm run dev`) 후 브라우저에서 `http://localhost:5173/` 에 접속합니다.
   * 로그인 화면에서 **[🌱 신규 온보딩부터 시작 (프로필/시간표 입력)]** 버튼을 누릅니다.
   * Q1 직무(예: 서비스 기획자)와 Q2 관심사를 입력한 뒤 Enter 키를 눌러 단계별로 진행하고, 선택 설문 건너뛰기 설득 모달을 확인합니다.
   * Final 서약 단계 종이 캔버스에 마우스/펜으로 **"동의"** 또는 **"네"**를 자유롭게 적으면, AI가 실시간으로 이를 인식하여 `✓ '동의' — 동의가 확인되었습니다.` 피드백과 함께 [시작하기] 버튼이 활성화되는 것을 확인하고 메인 캔버스로 진입합니다.
2. **동그라미(O) 확정 및 `/desk` 진화 맥락 영구 보존 확인**:
   * 미색 캔버스에 펜이나 마우스로 `UX 리서치와 사용자 인터뷰`를 적고 대기합니다 (`?fast=1` 가속 모드 지원).
   * 잉크가 증발한 여백에 AI가 등록된 직무에 맞춘 단일 가설 문장을 적으면, 문장 위에 펜으로 동그라미(`O`)를 그려 종이 속으로 흡수시킵니다.
   * 우측 하단 워터마크 펜 홀드(또는 주소창 `/desk`)로 이동하여 [진화 맥락] 탭에서 방금 확정한 어휘가 내 진화 맥락에 누적되었음을 확인합니다.
3. **토스페이먼츠 테스트 결제 및 금액 위변조 방어 확인**:
   * `/desk`의 [구독] 탭에서 **[Pro 플랜 업그레이드 (월 9,900원)]**를 누릅니다.
   * 토스페이먼츠 결제 모달에서 테스트 결제를 진행하면 백엔드 금액 위변조 검증(`POST /api/billing/confirm`)을 거쳐 즉시 `PRO MEMBER`로 활성화되는 것을 확인합니다.

### 바뀐 점과 그 이유
* **일괄 폼 방식에서 1질문 1화면 집중형 온보딩으로 전환**:
  * 초기에는 한 페이지에 모든 설문과 시간표를 나열하여 사용자의 피로도와 이탈률이 높았습니다.
  * 필수 질문을 전면에 배치하고 선택 질문을 후반부로 모아 건너뛰기를 자유롭게 허용하되, 건너뛰기 시 AI 맥락 학습의 이점을 설명하는 모달을 배치하여 참여율을 높였습니다.
* **정적 체크박스 동의 대신 AI 손글씨 멀티모달 자필 서약 캘리브레이션 채택**:
  * 잇적은 펜 스타일러스 손글씨 전용 서비스이므로, 체크박스 클릭보다 종이에 직접 동의를 적는 경험이 서비스의 정체성을 가장 직관적으로 전달합니다.
  * 필기 시 획수와 속도를 자동 캘리브레이션하여 무의식적 필기 습관 데이터를 수집하고, Gemini 비전 모델을 통해 긍정 동의 여부를 실시간 검증하도록 고도화했습니다.
* **세션 기반 자동 맥락 주입으로 개발자 편향 원천 제거**:
  * 기존에는 캔버스 추론 시 사용자 프로필이 누락되어 기본값(개발자)으로 가설이 쏠리는 문제가 있었습니다.
  * 백엔드 `inferRoute`에서 세션 쿠키를 기반으로 사용자의 직무, 취미, 실시간 루틴을 자동 주입하여 비개발자 직군에서도 정확한 맞춤형 사고 문장을 생성하도록 전면 개편했습니다.

### AI에게 맡긴 일과 내가 판단한 일
* **내가 판단한 일**:
  * Zero-UI 헌법을 엄수하기 위해 메인 필기 화면(`PaperCanvas.svelte`)에는 UI 요소를 일절 배제하고, 워터마크 펜 제스처 및 별도 라우트(`/desk`)로 관리 기능을 분리한 UX 아키텍처 결정.
  * 온보딩 단계별 인지 부하 감소를 위한 1질문 1화면 구조 및 자필 서약 캘리브레이션 인터랙션 설계.
  * 금액 위변조 원천 방어를 위한 사전 등록(`prepare`) 및 멱등성 캐시 아키텍처 수립.
* **AI에게 맡긴 일**:
  * HTML5 Canvas 픽셀 버퍼 스케일링 및 불투명 배경 JPEG 인코딩 알고리즘 구현.
  * Gemini 3.5 Flash Lite 멀티모달 프롬프트 엔지니어링 및 4단 감정 분류 JSON Schema 어댑터 작성.
  * Vitest 기반 통합 테스트 61종 및 TypeScript 타입 정의 작성.
