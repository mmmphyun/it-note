# 나의 앱 프로젝트 · 1/3 (중간 점검 1차)

### 이번에 만든 것
* **Zero-UI 스타일러스 캔버스 (`PaperCanvas.svelte`)**:
  * 미색 종이 질감(`#FAF8F5`)과 2400x1800 해상도의 스크롤/패닝 캔버스 작업 공간 구축.
  * 헤더, 푸터, 플로팅 툴바, 지우개 버튼이 전혀 없는 순수 필기 환경 구현.
  * `perfect-freehand`를 연동하여 필압(`pressure`)과 120Hz 포인터 궤적을 반응형 가상 DOM 리렌더링 병목 없이 Canvas Context2D로 직접 렌더링.
* **여유 호흡 잉크 증발(Decay) 상태 머신 (`decayTimer.ts`, `canvasLifecycle.ts`)**:
  * 펜을 뗀 시점부터 30초간 투명도 1.0을 온전히 유지하며 연상을 돕고, 이후 60초 동안 서서히 투명해지는 선형 감쇄 타이머 구현.
  * 빠른 검증을 위해 `?fast=1` 쿼리 파라미터 부여 시 3초 대기 + 5초 증발(총 8초)로 동작하는 배속 디버그 스위치 내장.
  * 펜 입력 도중(25초 경과 시점 등) 추가 펜 터치 발생 시 30초 대기 타이머가 자동으로 즉시 리셋되는 연속성 보장.
  * 증발 완료 시 디스크 I/O 없이 메모리 상에서 최소 바운딩 박스(`Cropped Bounding Box`)만 Base64 PNG로 추출 후 캔버스 획 정리.
* **한글 손글씨 획순 대필 및 O/X 기하학 제스처 루프 (`AiHandwriting.svelte`, `OxGestureLayer.svelte`, `gestureRecognizer.ts`)**:
  * 오픈소스 `tegaki` 코어 및 `nanum-pen-script` 손글씨 폰트를 연동하여 AI 단일 가설 문장을 한글 획순 애니메이션으로 여백에 렌더링.
  * 신발끈 공식(Shoelace formula) 및 시작-끝점 거리 비율($\frac{\|P_n - P_0\|}{L} < 0.35$, 면적비 $\ge 0.35$)을 통한 동그라미(`O`) 채택 제스처 인식.
  * CCW(Counter-Clockwise) 2획 선분 교차 및 단일 관통선/지그재그 반전($\ge 3$회)을 통한 엑스(`X`) 기각 제스처 인식.
  * `O` 입력 시 문장이 종이 속으로 스며들며 데스크 보관함으로 흡수(Sink-in)되고, `X` 입력 시 연기처럼 사라지며 오답이 배제된 새 문장이 재작성되는 인터랙션 완성.
* **펜촉 전용 워터마크 보관함 진입 (`PaperCanvas.svelte`, `DeskView.svelte`)**:
  * 손날(Palm) 터치 오작동을 차단하기 위해 `pointerType === 'pen'` 입력에 한해 우측 하단 워터마크 영역 400ms 이내 더블탭 + 800ms 홀드 시 보관함(`/desk`) 뷰 전환.

### 확인하는 방법 · 3단계 이내
1. **서버 실행 및 접속**:
   * 터미널에서 `npm run dev` 실행 후 브라우저로 `http://localhost:5173/?fast=1`에 접속합니다 (`?fast=1`을 붙이면 3초 대기 후 5초 만에 빠르게 증발합니다).
2. **필기 및 잉크 증발 대필 확인**:
   * 미색 종이 위에 스타일러스 펜(또는 마우스 드래그)으로 단어를 적거나 취소선을 긋고 손을 뗍니다.
   * 3초 후 글씨가 서서히 투명해지며 사라지고, 여백에 AI가 손글씨 획순 애니메이션으로 단 1개의 추론 문장을 적어 내려가는 것을 확인합니다.
3. **O / X 펜 마킹 및 워터마크 진입**:
   * AI가 적은 문장 위에 크게 동그라미(`O`)를 그리면 종이 아래로 스며들듯 흡수(Sink-in)되어 사라지고, 엑스(`X`)나 가로 취소선을 그으면 기각 후 다른 대안 문장으로 교체되는 것을 확인합니다.
   * 우측 하단의 흐릿한 `잇적` 워터마크를 펜촉으로 더블탭 후 길게 누르면 흡수된 문장들이 저장된 보관함(`/desk`) 화면으로 전환됩니다.

### 바뀐 점과 그 이유
* **Svelte 5 Runes 채택 및 Canvas 직접 그리기 분리**:
  * 초당 120개 이상 쏟아지는 고주파 스타일러스 포인터 이벤트를 Svelte 반응형 상태(`$state`)로 매 프레임 업데이트할 경우 GC(가비지 컬렉터) 및 vDOM 병목으로 필기 딜레이가 발생함.
  * 포인터 궤적 버퍼는 순수 TypeScript 클래스(`CanvasLifecycleEngine`)와 HTML5 Canvas Context2D에서 직접 처리하고, 문장 등장/흡수 수명 주기만 Svelte 5 Runes로 바인딩하여 120Hz 무지연 필기를 달성함.
* **tegaki 기반 한글 획순 대필 엔진 통합**:
  * 임의의 사용자 문장을 손글씨 획순으로 렌더링하기 위해 방대한 사전 벡터 데이터베이스를 구축하는 대신, 표준 오픈소스 `tegaki` 런타임과 나눔손글씨 폰트 번들을 번들링하여 추가 서버 통신 없이 브라우저 단독으로 가볍게 획순 애니메이션을 구현함.
* **단위 및 통합 테스트 100% 자동화**:
  * 브라우저 없이도 CI/CD 및 커밋 하드가드 단계에서 회귀를 차단하기 위해 Vitest 가상 타이머(`vi.useFakeTimers()`) 기반 수명 주기 테스트 16건을 구축함.

### AI에게 맡긴 일과 내가 판단한 일
* **내가 판단한 일**:
  * 120Hz 고주파 스타일러스 필기 환경에서 반응형 리렌더링 병목을 없애기 위해 React 대신 Svelte 5 Runes 및 순수 TS 캔버스 버퍼 아키텍처 선택.
  * 손날(Palm) 오작동 방지를 위한 `pointerType === 'pen'` 전용 워터마크 진입 제약 조건(400ms 더블탭 + 800ms 홀드) 설계.
  * 지우개 도구를 없애고 사용자의 취소선/덧칠 행위를 삭제가 아닌 추론의 핵심 의도(`THOUGHT_PIVOT`) 데이터로 보존하는 Zero-UI 인터랙션 설계.
* **AI에게 맡긴 일**:
  * `perfect-freehand` 연동을 통한 필압 기반 다각형 스트로크 외곽선 좌표 연산 코드 작성.
  * Shoelace 다각형 면적 공식 및 CCW 선분 교차 알고리즘 기반 O/X 기하학 판별 수식 코드 구현.
  * 30초 대기 + 60초 증발 타이머 상태 머신 및 가상 타이머 Vitest 단위/통합 테스트 코드 일체 작성.
