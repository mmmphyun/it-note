# 나의 앱 프로젝트 · 1/3 (중간 점검 1차)

### 이번에 만든 것
* **Zero-UI 순수 스타일러스 캔버스 (`PaperCanvas.svelte`)**:
  * 미색 종이 질감(`#FAF8F5`)과 2400×1800 해상도의 스크롤/패닝 무한 종이 작업 환경 구축.
  * 헤더, 푸터, 툴바, 버튼, 지우개 UI를 일절 배제하고 오직 펜과 워터마크만 존재하는 미니멀 인터페이스 구현.
  * `perfect-freehand` 알고리즘을 연동하여 120Hz 필압(`pressure`) 궤적을 반응형 가상 DOM 병목 없이 Canvas Context2D로 직접 렌더링.
* **여유 호흡 잉크 증발(Decay) 및 휘발 상태 머신 (`decayTimer.ts`, `canvasLifecycle.ts`)**:
  * 펜을 뗀 후 30초간 투명도 1.0 유지(착상 지원), 이후 60초간 점진적 증발(총 90초) 타이머 구현 (`?fast=1` 디버그 시 8초 완료).
  * 추가 필기 발생 시 증발 타이머 자동 리셋 및 원본 필기 획의 인메모리 최소 바운딩 박스(Cropped Bbox) 추출 후 캔버스 자동 정리.
* **반응형 어절 개행 손글씨 대필 엔진 (`AiHandwriting.svelte`, `canvasLifecycle.ts`)**:
  * 오픈소스 `tegaki` 및 나눔손글씨 폰트를 연동하여 AI 가설 문장을 한글 획순 애니메이션으로 여백에 렌더링.
  * 사용자 뷰포트 가시 너비 기반 동적 어절 단위 개행(`\n`) 및 Tegaki 내부 오버레이의 강제 줄바꿈 차단(`white-space: pre !important`)을 적용하여 텍스트 쪼개짐 및 우측 쏠림 현상 원천 해소.
* **다중 획 제스처 지연 판정 및 피드백 루프 (`gesture.ts`, `canvasLifecycle.ts`)**:
  * 신발끈 공식(Shoelace formula, 동그라미 `O`)과 CCW 선분 교차(2획 `X` 및 단일 취소선) 판정 알고리즘 탑재.
  * 한 획 직후 성급하게 판정하지 않고, 사용자의 필기가 멈춘 것을 감지하는 1500ms 유예 타이머 버퍼를 적용하여 2획 이상의 `X` 및 추가 입력 연속성 보장.
  * `O` 입력 시 종이 아래로 스며드는 Sink-in 애니메이션 후 확정 노트 저장, `X` 입력 시 연기처럼 사라지는 Smoke-out 애니메이션 후 오답을 배제한 다음 대안 문장 생성.
* **펜촉 전용 워터마크 보관함 진입 (`PaperCanvas.svelte`, `DeskView.svelte`)**:
  * 팜 리젝션(Palm rejection)을 위해 `pointerType === 'pen'`에 한해 우측 하단 워터마크 400ms 더블탭 + 800ms 홀드 시 확정 노트 보관함(`/desk`) 전환.

### 확인하는 방법 · 3단계 이내
1. **웹 주소 접속**:
   * 브라우저로 `https://it-note-app.web.app/?fast=1`에 접속합니다 (`?fast=1` 파라미터로 3초 대기 후 5초 증발 동작).
2. **필기 및 AI 손글씨 대필 확인**:
   * 미색 종이 위에 스타일러스 펜(또는 마우스)으로 메모를 작성하고 손을 뗍니다.
   * 잠시 후 글씨가 서서히 투명해지며 사라지고, 여백에 AI가 손글씨 획순으로 단 1개의 추론 문장을 적는 것을 확인합니다.
3. **O / X 마킹 및 보관함 이동**:
   * AI 문장 위에 동그라미(`O`)를 치면 종이 속으로 스며들어 저장되고, 엑스(`X`)를 치면 문장이 사라진 후 새로운 대안 문장이 작성됩니다.
   * 우측 하단의 흐릿한 `잇적` 워터마크를 펜촉으로 더블탭 후 길게 누르면 저장된 확정 노트를 열람하는 보관함(`/desk`)으로 전환됩니다.

### 바뀐 점과 그 이유
* **Tegaki 텍스트 레이아웃 강제 래핑 차단**:
  * 브라우저 기본 CSS(`pre-wrap`) 동작으로 인해 단어 중간('클라우드' $\to$ '클라' + '우드')이 임의로 쪼개지며 Chromium Range 앵커 오차로 인한 텍스트 우측 쏠림이 발생했습니다.
  * 내부 DOM 오버레이에 `white-space: pre !important`를 강제하고, 뷰포트 너비 기반 사전 어절 단위 개행(`\n`) 주입 방식으로 변경하여 글자 깨짐 및 자간 왜곡을 완전히 해결했습니다.
* **다중 획 제스처 1.5초 유예 타이머 도입**:
  * 기존에는 한 획이 끝나자마자 판정을 시도하여 2획으로 작성되는 `X` 표시나 취소선 입력 도중 AI 문장이 성급하게 재작성되는 문제가 있었습니다.
  * 제스처 획을 인메모리 버퍼에 수집하고 사용자 펜 입력이 1.5초간 멈추었을 때 최종 판정하도록 수정하여 다획 제스처 입력 안정성을 확보했습니다.

### AI에게 맡긴 일과 내가 판단한 일
* **내가 판단한 일**:
  * 고주파(120Hz) 스타일러스 입력 환경에서 vDOM 리렌더링 오버헤드를 배제하기 위해 Svelte 5 Runes와 Canvas Context2D 직접 그리기 분리 아키텍처 결정.
  * 사용자의 취소선이나 덧칠을 삭제가 아닌 의도 파악(`THOUGHT_PIVOT`)을 위한 보존 데이터로 정의하고 UI 툴바/지우개 없는 Zero-UI 설계 확정.
  * 획 작성 즉시 판정이 아닌 사용자 입력 멈춤(1.5초) 감지 후 제스처를 최종 판정하는 인터랙션 규칙 수립.
* **AI에게 맡긴 일**:
  * `perfect-freehand` 기반의 필압 감응형 외곽선 메쉬 생성 코드 구현.
  * Shoelace 다각형 면적 공식 및 CCW 선분 교차 알고리즘 기반 O/X 기하학 판별 로직 작성.
  * 뷰포트 가시 영역 산출 및 글자 픽셀 가중치 기반 동적 어절 개행 알고리즘 작성.
  * Vitest 가상 타이머 기반 캔버스 수명 주기, 제스처, 플러그인 단위/통합 테스트 코드(30개 테스트) 작성.
